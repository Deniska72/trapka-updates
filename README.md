# Trapka

Windows-лаунчер и оверлей с локальным распознаванием видимых персонажей.

## Скачать

[Trapka.zip](https://github.com/Deniska72/trapka-updates/releases/latest/download/Trapka.zip) · [Trapka.exe](https://github.com/Deniska72/trapka-updates/releases/latest/download/Trapka.exe)

Распакуйте архив, завершите старую Trapka и запустите новый файл. Нажмите «ЗАПУСТИТЬ», затем вернитесь в ROB RUN. Insert — меню, F2 — слой, Ctrl+End — выход. Требуется Windows x64 и оконный режим игры или окно без рамки.

## Обновления

Начиная с v0.6.0.0 лаунчер проверяет подписанный манифест при запуске и раз в минуту, пока открыт. Новая версия применяется, когда оверлей завершён. При недоступности сети или ошибке проверки текущая версия сохраняется.

Встроенный источник: https://raw.githubusercontent.com/Deniska72/trapka-updates/main/update.xml

Пакеты проверяются RSA/SHA-256, размером и SHA-256. Закрытый ключ подписи в репозитории и релизах отсутствует. Настройки и кэш находятся в `%LOCALAPPDATA%\Trapka`.

## Ограничения распознавания

Рамки строятся по изображению. Возможны пропуски и ложные срабатывания; модель может выделять NPC и собственного персонажа. Она не видит за стенами и не получает реальные имена, здоровье или дистанцию. Проценты обозначают уверенность модели. Обработка локальная, без отправки кадров в интернет. Чтение памяти игры, драйверы и внедрение не используются.

## Исходники и лицензии

Полный исходный код, зависимости и сценарий сборки находятся в `Trapka-source.zip` каждого релиза. ONNX Runtime 1.20.1 — MIT, YOLOX-Tiny — Apache-2.0; уведомления включены в архив и EXE. Сценарий `Sign-Release.ps1` требует отдельного закрытого ключа издателя.
